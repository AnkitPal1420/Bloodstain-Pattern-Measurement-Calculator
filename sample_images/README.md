# Sample Images Directory

This directory stores sample bloodstain images for testing and demonstration in **Milestone 2 (OpenCV Image Processing)**.

## Guidelines
- **Synthetic & Educational Only**: Use synthetic, digitally generated, or openly licensed forensic training images.
- **Privacy & Safety**: Do **not** upload real crime scene photos, private forensic case files, or uncredited copyrighted material.
- **Format**: High-contrast JPEG or PNG images showing distinct stains against uniform backgrounds are optimal.
